# ❤️ Happy Birthday Naushin 🎂

A small interactive birthday surprise webpage made with love for **Naushin**. ❤️

This project is a simple romantic HTML/CSS/JavaScript experience featuring a dark red-and-black theme, floating hearts, a birthday surprise, and a small interactive game.

## ✨ Features

- 🖤 Black & red romantic theme
- ❤️ Animated floating hearts
- 🎂 Birthday greeting for Naushin
- 📅 Birthday date: **2 October 2001**
- 🎁 Interactive surprise gift
- 🎮 Mini "Catch My Love" game
- 💌 Romantic Hindi Shayari
- 📱 Responsive design for mobile and desktop
- ⚡ No frameworks or backend required

## 🎮 Mini Game

### Catch My Love ❤️

Click as many hearts as possible within **10 seconds**.

Your score determines the final surprise message. 😄❤️

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Animations
- Emoji-based UI
